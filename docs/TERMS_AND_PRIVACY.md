## 3. Privacy Policy and Data Sovereignty

PSD Technologies upholds a strict principle of absolute data privacy and zero surveillance.

1. **Zero Telemetry and Zero Analytics**:
   - The Software contains zero tracking beacons, zero telemetry collection modules, zero advertising identifiers, and zero third-party analytical SDKs.
   - The Software does not monitor, collect, log, or transmit information regarding files opened, playback history, media metadata, hardware fingerprints, or user behavior.
2. **Local Data Isolation**:
   - All user preferences, selected themes, custom equalizer presets, and application configurations are stored strictly on the local machine within the user's isolated application directory:
     `%LOCALAPPDATA%\OmniPlayer\`
   - Configuration files are never synchronized to external servers unless explicitly performed by the user's operating system roaming profile.
3. **Diagnostic Logging**:
   - Crash logs and unhandled exceptions are written exclusively to a local text file:
     `%LOCALAPPDATA%\OmniPlayer\crash.log`
   - Diagnostic files are never transmitted automatically to PSD Technologies or any remote endpoint. Users may choose to manually inspect or share logs when requesting technical support via `prabhukannanmail@gmail.com`.

## 4. Network Streaming and IPTV User Consent

1. **Direct Client-to-Endpoint Connectivity**:
   - When streaming network content, live IPTV feeds, or using the Online Video Downloader, the Software establishes direct HTTP/HTTPS connections from your client machine to the host content delivery network (CDN) or media server.
   - Traffic is never routed through proxy servers, relay tunnels, or intermediate infrastructure owned or managed by PSD Technologies.
2. **Public and Free-to-Air Feeds**:
   - The IPTV Hub provides convenient access to publicly accessible, free-to-air broadcast streams syndicated via public repositories (such as the community-maintained IPTV-org catalog).
   - PSD Technologies does not host, broadcast, rebroadcast, store, or control any multimedia content streamed through the player.
3. **Acceptable Use and User Responsibility**:
   - Users are solely responsible for ensuring that their consumption, recording, and downloading of live streams and online videos comply with intellectual property laws, regional broadcasting regulations, and the terms of service of respective content providers.
